## ✨ Возможности

### ⏳ Обратный отсчёт

Создавайте события с определённой датой и временем и следите за оставшимся временем:

* Дни
* Часы
* Минуты
* Секунды

ChronoLeaf постоянно обновляет обратный отсчёт, используя местное системное время вашего компьютера.

### 📅 Несколько событий

Создавайте и управляйте несколькими таймерами одновременно.

У каждого события есть собственные:

* Название
* Дата
* Время
* Обратный отсчёт
* Статус

События также можно перемещать в списке с помощью кнопок **«Вверх»** и **«Вниз»** непосредственно в карточке события.

### 🗑️ Управление событиями

Управляйте отдельными событиями прямо в их карточках.

Доступные действия:

* ✏️ Редактирование события
* 🗑️ Удаление конкретного события
* ⬆️ Перемещение события вверх
* ⬇️ Перемещение события вниз

Доступность кнопок перемещения автоматически зависит от положения события в списке.

### 🌐 Три языка

ChronoLeaf поддерживает три языка:

* 🇷🇺 Русский
* 🇬🇧 Английский
* 🇨🇳 Китайский

Язык приложения можно изменить в настройках.

### 🎨 Современный интерфейс

ChronoLeaf использует тёмный минималистичный интерфейс, ориентированный на удобство чтения и повседневное использование.

Цветовые индикаторы помогают быстро оценить срочность предстоящих событий.

### 🟢 Статусы событий

Статусы отображаются в зависимости от оставшегося времени:

* 🟢 **Обычный** — до события ещё достаточно времени
* 🟡 **Внимание** — событие приближается
* 🔴 **Критический** — времени осталось очень мало или событие уже прошло

### 🪟 Настройка окна

Настраивайте поведение ChronoLeaf как окна рабочего стола.

Доступные параметры:

* **Прозрачность окна** — регулировка непрозрачности
* **Поверх всех окон** — отображение ChronoLeaf поверх других окон
* **Только таймеры** — скрытие лишних элементов интерфейса для фокусировки на обратном отсчёте

Кнопка **Settings** остаётся доступной в режиме «Только таймеры», поэтому интерфейс всегда можно вернуть.

### 💾 Локальное хранение данных

События и настройки сохраняются локально на вашем компьютере.

Для использования ChronoLeaf не требуется учётная запись.

### ⚙️ Настройки

ChronoLeaf позволяет адаптировать приложение под ваши предпочтения.

Доступные настройки:

* Язык приложения
* Порог жёлтого статуса
* Порог красного статуса
* Прозрачность окна
* Отображение поверх всех окон
* Режим «Только таймеры»

## 🆕 Что нового в версии 2.2.1

Версия 2.2.1 сосредоточена на доработке существующего приложения и улучшении процесса сборки, а не на добавлении крупных новых функций.

* **Улучшенный билдер** — процесс сборки и установки стал более продуманным.
* **Доработка приложения** — дополнительное внимание уделено существующему интерфейсу и поведению приложения.
* **Привычные возможности** — ChronoLeaf сохраняет знакомый функционал, настройки и порядок управления событиями.

Цель обновления — сделать сборку и использование ChronoLeaf более удобными, не меняя без необходимости то, что уже работает.

## 🖥️ Установка

Самый простой способ установить ChronoLeaf — воспользоваться включённым в проект билдером-установщиком.

### Автоматическая установка

1. Скачайте `install.bat`.
2. Запустите файл.
3. Дождитесь завершения сборки и установки.
4. ChronoLeaf появится на рабочем столе.

Билдер загружает необходимые файлы приложения и подготавливает ChronoLeaf к использованию.

> **Примечание:** для установки и сборки требуется подключение к интернету.

## 📋 Системные требования

* Windows 10 или Windows 11
* Подключение к интернету для установки и сборки
* Установленный Python, доступный билдеру

### Рекомендуемая версия Python

**По-прежнему рекомендуем Python 3.11** — для наиболее предсказуемого процесса сборки.

При этом в версии 2.2.1 билдер стал более продуманным, поэтому вы можете сначала попробовать собрать ChronoLeaf с уже установленной у вас версией Python, не устанавливая другую сразу.

Совместимость зависит от версии Python и доступности совместимых зависимостей. Если сборка завершится ошибкой, попробуйте Python 3.11.

При установке Python обязательно включите параметр **«Add Python.exe to PATH»** или **«Add Python to PATH»**.

> **Важно:** билдеру требуется Python для сборки приложения. Если готовый EXE включает необходимые компоненты среды выполнения и зависимости, конечному пользователю, как правило, не нужно устанавливать Python отдельно.

### Совместимость с Windows

ChronoLeaf разработан для **Windows 10 и Windows 11** — это основные целевые версии операционной системы.

Обратный отсчёт синхронизируется с местным системным временем компьютера. Расчёт событий выполняется с учётом текущих даты и времени, установленных в Windows.
