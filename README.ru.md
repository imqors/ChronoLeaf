## ✨ Возможности

### ⏳ Обратный отсчёт

Создавайте события с определённой датой и временем и точно отслеживайте, сколько времени осталось.

Обратный отсчёт показывает:

- Дни
- Часы
- Минуты
- Секунды

Таймер постоянно обновляется, поэтому вы всегда видите актуальное оставшееся время.

### 📅 Несколько событий

Создавайте и одновременно отслеживайте несколько событий.

Каждое событие может иметь собственные:

- Название
- Дату
- Время
- Обратный отсчёт
- Статус

### 🌐 Три языка

ChronoLeaf поддерживает три языка:

- 🇷🇺 Русский
- 🇬🇧 Английский
- 🇨🇳 Китайский

Язык приложения можно изменить в настройках.

### 🎨 Современный интерфейс

ChronoLeaf использует тёмный, современный и минималистичный интерфейс, созданный для удобного просмотра важной информации.

Понятные визуальные индикаторы позволяют быстро определить состояние каждого события.

### 🟢 Статусы событий

В зависимости от оставшегося времени события получают соответствующий статус:

- 🟢 **Нормально** — до события ещё достаточно времени
- 🟡 **Внимание** — событие приближается
- 🔴 **Критично** — до события осталось совсем немного времени

### 💾 Локальное хранение

События и настройки приложения сохраняются локально на компьютере.

Для использования ChronoLeaf не требуется регистрация или создание аккаунта.

### ⚙️ Настройки

ChronoLeaf позволяет настроить приложение в соответствии с вашими предпочтениями.

Настройки сохраняются локально и применяются к приложению.

## 🖥️ Установка

Самый простой способ установить ChronoLeaf — использовать встроенный установщик.

### Автоматическая установка

1. Скачайте `install.bat`.
2. Запустите файл.
3. Дождитесь завершения установки.
4. На рабочем столе появится папка `ChronoLeaf`.
5. Запустите `ChronoLeaf.exe`.

Установщик автоматически скачивает необходимые файлы, устанавливает зависимости и собирает приложение.

> **Примечание:** во время установки требуется подключение к интернету.

---

## 📋 Системные требования

- Windows 10
- Windows 11
- Подключение к интернету для установки

При использовании `install.bat` вручную устанавливать Python не требуется.
