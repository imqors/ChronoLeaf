## ✨ Возможности

### ⏳ Обратный отсчёт

Создавайте события с определённой датой и временем и отслеживайте оставшееся время:

- Дни
- Часы
- Минуты
- Секунды

ChronoLeaf постоянно обновляет отсчёт, позволяя точно видеть, сколько времени осталось до события.

### 📅 Несколько событий

Создавайте и одновременно отслеживайте несколько событий.

Каждое событие имеет собственные:

- Название
- Дату
- Время
- Обратный отсчёт
- Статус

### 🌐 Три языка

ChronoLeaf поддерживает три языка:

- 🇷🇺 Русский
- 🇬🇧 Английский
- 🇨🇳 Китайский

Язык приложения можно изменить в настройках.

### 🎨 Современный интерфейс

ChronoLeaf использует тёмный, минималистичный и современный интерфейс, ориентированный на удобство и читаемость.

### 🟢 Статусы событий

В зависимости от оставшегося времени события отображаются с разными статусами:

- 🟢 **Нормально** — до события ещё достаточно времени
- 🟡 **Внимание** — событие приближается
- 🔴 **Критично** — до события осталось совсем немного времени

### 💾 Локальное хранение

События и настройки сохраняются локально на компьютере.

Для использования ChronoLeaf не требуется создавать аккаунт.

### ⚙️ Настройки

ChronoLeaf позволяет настраивать приложение в соответствии с вашими предпочтениями.

## 🖥️ Установка

Самый простой способ установить ChronoLeaf — использовать встроенный установщик.

### Автоматическая установка

1. Скачайте `install.bat`
2. Запустите файл
3. Дождитесь завершения установки
4. На рабочем столе появится папка `ChronoLeaf`

Установщик автоматически скачивает необходимые файлы и подготавливает приложение к работе.

> **Примечание:** для установки требуется подключение к интернету.

---

## 📋 Требования

- Windows 10 или Windows 11
- Подключение к интернету для установки

При использовании установщика вручную устанавливать Python не требуется.

## 🔄 Обновления

Для установки или обновления ChronoLeaf снова запустите `install.bat`.
