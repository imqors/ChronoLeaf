## ✨ Возможности

### ⏳ Обратный отсчёт

Создавайте события с определённой датой и временем и точно отслеживайте, сколько времени осталось.

Обратный отсчёт показывает:

* Дни
* Часы
* Минуты
* Секунды

Таймер постоянно обновляется, поэтому вы всегда видите актуальное оставшееся время.

### 📅 Несколько событий

Создавайте и одновременно отслеживайте несколько событий.

Каждое событие имеет собственные:

* Название
* Дату
* Время
* Обратный отсчёт
* Статус

Порядок событий можно изменять прямо в карточке с помощью кнопок **вверх** и **вниз**.

### 🗑️ Управление событиями

Каждое событие можно управлять непосредственно из его карточки.

Доступны следующие действия:

* ✏️ Редактирование события
* 🗑️ Удаление конкретного события
* ⬆️ Перемещение события вверх
* ⬇️ Перемещение события вниз

Кнопки перемещения автоматически отображаются в зависимости от положения события в списке.

### 🌐 Три языка

ChronoLeaf поддерживает три языка:

* 🇷🇺 Русский
* 🇬🇧 Английский
* 🇨🇳 Китайский

Язык приложения можно изменить в настройках.

### 🎨 Современный интерфейс

ChronoLeaf использует тёмный, современный и минималистичный интерфейс, созданный для удобного просмотра важной информации.

Понятные визуальные индикаторы позволяют быстро определить состояние каждого события.

### 🟢 Статусы событий

В зависимости от оставшегося времени события получают соответствующий статус:

* 🟢 **Нормально** — до события ещё достаточно времени
* 🟡 **Внимание** — событие приближается
* 🔴 **Критично** — до события осталось совсем немного времени

### 🪟 Настройка окна

ChronoLeaf позволяет настроить поведение окна приложения.

Доступны:

* **Прозрачность окна** — настройка уровня прозрачности
* **Поверх других окон** — закрепление ChronoLeaf поверх остальных окон
* **Только таймеры** — скрытие лишних элементов интерфейса для отображения только таймеров

В режиме **«Только таймеры»** кнопка **«Настройки»** остаётся доступной, поэтому режим всегда можно отключить.

### 💾 Локальное хранение

События и настройки приложения сохраняются локально на компьютере.

Для использования ChronoLeaf не требуется регистрация или создание аккаунта.

### ⚙️ Настройки

ChronoLeaf позволяет настроить приложение в соответствии с вашими предпочтениями.

Доступны следующие настройки:

* Язык приложения
* Порог статуса «Внимание»
* Порог статуса «Критично»
* Прозрачность окна
* Поверх других окон
* Режим «Только таймеры»

Все настройки сохраняются локально.

## 🖥️ Установка

Самый простой способ установить ChronoLeaf — использовать встроенный установщик.

### Автоматическая установка

1. Скачайте `install.bat`.
2. Запустите файл.
3. Дождитесь завершения установки.
4. На рабочем столе появится папка `ChronoLeaf`.
5. Запустите `ChronoLeaf.exe`.

Установщик автоматически скачивает необходимые файлы, устанавливает зависимости и собирает приложение.

> **Примечание:** во время установки требуется подключение к интернету.

---

## 📋 Системные требования

* Windows 10
* Windows 11
* Подключение к интернету для установки

> **⚠️ Важно:** перед запуском `install.bat`, пожалуйста, установите **Python 3.11 или новее**.
> Если Python не установлен или неправильно добавлен в PATH, это может привести к тому, что установка ChronoLeaf не завершится успешно.
>
> При установке Python обязательно включите опцию **“Add Python.exe to PATH”** (или **“Add Python to PATH”**) в нижней части окна установщика.
>
> После этого запустите `install.bat`. Все остальные необходимые зависимости ChronoLeaf установщик установит автоматически.
