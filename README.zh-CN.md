## ✨ 功能

### ⏳ 倒计时

创建指定日期和时间的事件，并实时查看剩余时间：

- 天
- 小时
- 分钟
- 秒

ChronoLeaf 会持续更新倒计时，让你准确了解距离事件还有多长时间。

### 📅 多个事件

可以同时创建和管理多个倒计时事件。

每个事件都有自己的：

- 名称
- 日期
- 时间
- 倒计时
- 状态

### 🌐 三种语言

ChronoLeaf 目前支持三种语言：

- 🇷🇺 俄语
- 🇬🇧 英语
- 🇨🇳 中文

可以在设置中切换应用语言。

### 🎨 现代界面

ChronoLeaf 使用深色、简洁、现代的界面设计，注重可读性和使用体验。

### 🟢 事件状态

根据剩余时间，事件会显示不同的状态：

- 🟢 **正常** — 距离事件还有充足时间
- 🟡 **注意** — 事件正在临近
- 🔴 **紧急** — 距离事件已经非常近

### 💾 本地存储

事件和设置都会保存在用户的电脑本地。

使用 ChronoLeaf 不需要注册账号。

### ⚙️ 自定义设置

ChronoLeaf 提供多种设置选项，可以根据个人习惯调整应用。

## 🖥️ 安装

最简单的安装方式是使用项目提供的安装程序。

### 自动安装

1. 下载 `install.bat`
2. 运行该文件
3. 等待安装完成
4. ChronoLeaf 文件夹将被创建在桌面上

安装程序会自动下载所需文件并准备好 ChronoLeaf。

> **注意：** 安装过程中需要连接互联网。

---

## 📋 系统要求

- Windows 10 或 Windows 11
- 安装时需要互联网连接

使用安装程序时无需手动安装 Python。

---

## 🔄 更新

如果需要安装或更新 ChronoLeaf，只需再次运行 `install.bat`。
