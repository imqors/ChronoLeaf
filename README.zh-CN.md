## ✨ 功能特性

### ⏳ 倒计时

创建包含指定日期和时间的事件，并查看剩余时间：

* 天
* 小时
* 分钟
* 秒

ChronoLeaf 会持续更新倒计时，并根据电脑的本地系统时间计算剩余时间。

### 📅 多个事件

同时创建和管理多个倒计时。

每个事件都有自己的：

* 名称
* 日期
* 时间
* 倒计时
* 状态

还可以直接在事件卡片中使用 **上移** 和 **下移** 按钮调整事件顺序。

### 🗑️ 事件管理

直接通过事件卡片管理各个事件。

可执行的操作包括：

* ✏️ 编辑事件
* 🗑️ 删除指定事件
* ⬆️ 将事件上移
* ⬇️ 将事件下移

移动按钮会根据事件在列表中的位置自动调整可用状态。

### 🌐 三种语言

ChronoLeaf 目前支持三种语言：

* 🇷🇺 俄语
* 🇬🇧 英语
* 🇨🇳 中文

你可以在设置中更改应用语言。

### 🎨 现代化界面

ChronoLeaf 采用深色、简约的界面设计，注重可读性和日常使用体验。

通过不同的颜色指示器，可以快速了解即将发生的事件有多紧急。

### 🟢 事件状态

系统会根据剩余时间显示不同的事件状态：

* 🟢 **正常** — 距离事件还有充足时间
* 🟡 **注意** — 事件即将到来
* 🔴 **紧急** — 剩余时间很少，或事件已经过去

### 🪟 窗口自定义

可以根据个人习惯自定义 ChronoLeaf 的窗口行为。

可用选项包括：

* **窗口透明度** — 调整窗口的不透明程度
* **窗口置顶** — 让 ChronoLeaf 始终显示在其他窗口上方
* **仅显示计时器** — 隐藏不必要的界面元素，专注于倒计时

在“仅显示计时器”模式下，**Settings** 按钮仍然可用，因此可以随时恢复完整界面。

### 💾 本地存储

所有事件和设置都保存在你的电脑本地。

使用 ChronoLeaf 无需注册账户。

### ⚙️ 自定义设置

ChronoLeaf 提供多种设置，可根据个人偏好调整应用。

设置包括：

* 应用语言
* 黄色状态阈值
* 红色状态阈值
* 窗口透明度
* 窗口置顶
* 仅显示计时器模式

## 🆕 2.2.1 版本更新

2.2.1 版本主要针对现有应用和构建流程进行完善，而不是引入大量新功能。

* **构建器改进** — 对构建和安装流程进行了更周密的整理与优化。
* **应用细节优化** — 进一步完善现有界面和应用行为。
* **保留核心体验** — ChronoLeaf 保留原有功能、设置以及事件管理方式。

本次更新旨在让 ChronoLeaf 的构建和使用更加顺畅，同时避免不必要地改变已有功能。

## 🖥️ 安装

推荐使用项目附带的构建器和安装脚本来安装 ChronoLeaf。

### 自动安装

1. 下载 `install.bat`。
2. 运行该文件。
3. 等待构建和安装完成。
4. ChronoLeaf 将出现在桌面上。

构建器会自动下载所需的应用文件，并完成 ChronoLeaf 的准备工作。

> **注意：** 安装和构建过程中需要连接互联网。

---

## 📋 系统要求

* Windows 10 或 Windows 11
* 安装和构建时需要互联网连接
* 已安装且构建器能够访问的 Python

### 推荐的 Python 版本

**我们仍然推荐使用 Python 3.11**，以获得更稳定、可预测的构建体验。

不过，2.2.1 版本的构建器经过了进一步完善，因此你可以先尝试使用电脑上已经安装的 Python 版本进行构建，无需立即更换版本。

兼容性取决于 Python 版本以及相关依赖是否支持该版本。如果构建失败，建议尝试 Python 3.11。

安装 Python 时，请务必启用 **“Add Python.exe to PATH”** 或 **“Add Python to PATH”** 选项。

> **重要提示：** 构建器需要使用 Python 来构建应用。如果最终生成的 EXE 已包含所需的运行环境和依赖项，普通用户通常无需单独安装 Python。

### Windows 兼容性

ChronoLeaf 专为 **Windows 10 和 Windows 11** 设计，这两个版本是本项目的主要目标平台。

倒计时会根据电脑的本地系统时间同步更新，并按照 Windows 中设置的当前日期和时间计算事件剩余时间。
